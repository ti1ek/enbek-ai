# Skill: KZ Legal Citation Formatter

## Назначение

Форматирует все ссылки на нормативно-правовые акты Республики Казахстан по единому стандарту казахстанского юридического цитирования. Применяется к тексту ответа перед его отображением пользователю.

---

## Стандарт цитирования

### Трудовой кодекс РК (основной источник)

```
ст. {N} ТК РК                         — статья без пункта
ст. {N} п. {M} ТК РК                  — статья и пункт
ст. {N} п. {M} пп. {K} ТК РК          — статья, пункт и подпункт
ст. {N} п. {M} пп. {K}) ТК РК         — подпункт с закрывающей скобкой
```

**URL:** `https://adilet.zan.kz/rus/docs/K1500000414#z{N}`

### Социальный кодекс РК

```
ст. {N} Социального кодекса РК
ст. {N} п. {M} Социального кодекса РК
```

**URL:** `https://adilet.zan.kz/rus/docs/K2300000224#z{N}`

### КоАП РК

```
ст. {N} КоАП РК
ст. {N} п. {M} КоАП РК
```

**URL:** `https://adilet.zan.kz/rus/docs/K1400000235#z{N}`

### Нормативные постановления Верховного суда РК

```
п. {N} НП ВС РК от {дата} № {номер}
```

URL берётся из метаданных найденного чанка.

### Постановления Правительства РК

```
п. {N} ПП РК от {дата} № {номер}
```

### Разъяснения Министерства труда и социальной защиты РК

Если URL передан — оформить как Markdown-ссылку:
```
[Разъяснение Минтруда РК](url)
```
Если URL отсутствует:
```
Разъяснение Минтруда РК (dialog.egov.kz)
```

---

## Правила отображения URL

URL берётся из метаданных найденного чанка (`url` поле).

- Если URL передан → оформить как Markdown-ссылку: `[ст. N ТК РК](url)`. Текст ссылки = реквизит статьи, href = URL. НЕ вставлять голый URL в текст.
- Если URL отсутствует (поле пустое или null) → показать цитату **без ссылки**, только название документа и реквизиты. Не сообщать пользователю о недоступности ссылки.

Ссылка должна быть ВНУТРИ предложения, не отдельной строкой после текста.

❌ Неверно:
```
Работнику полагается 24 дня отпуска.
[ст. 88 ТК РК](https://adilet.zan.kz/rus/docs/K1500000414#z88)
```

✅ Верно:
```
Согласно [ст. 88 ТК РК](https://adilet.zan.kz/rus/docs/K1500000414#z88), работнику полагается 24 дня отпуска.
```

✅ Верно для Минтруда:
```
[Разъяснение Минтруда РК](https://dialog.egov.kz/blogs/all-questions/12345) подтверждает: компенсация выплачивается за все дни.
```

Пример без URL:
```
ст. 52 п. 1 пп. 6) ТК РК
```

## Правила применения

1. **Иерархия документов** (от высшего к низшему):
   - Кодексы (ТК, Соц) → имеют приоритет
   - КоАП → административная ответственность
   - Постановления Правительства → подзаконные акты
   - НП Верховного суда → судебная практика
   - Разъяснения Минтруда → методические рекомендации

2. **Форматирование чисел:**
   - Статьи: арабские цифры без слова «номер»
   - Пункты: арабские цифры
   - Подпункты: цифры или буквы со скобкой: `1)`, `а)`

3. **Сокращения (обязательные):**
   - Трудовой кодекс → **ТК РК**
   - Социальный кодекс → **Социального кодекса РК** (полностью при первом упоминании)
   - Кодекс об административных правонарушениях → **КоАП РК**
   - Нормативное постановление Верховного суда → **НП ВС РК**
   - Постановление Правительства → **ПП РК**

4. **Запрещённые форматы:**
   - ❌ «статья 52 ТК»
   - ❌ «ст.52 ТК РК» (без пробела)
   - ❌ «Статья 52 Трудового Кодекса»
   - ✅ «ст. 52 ТК РК»

## Примеры преобразования

| До (неформатированный) | После (отформатированный) |
|---|---|
| «статья 52 трудового кодекса» | «ст. 52 ТК РК» |
| «ст. 52 п.1 пп.1) ТК» | «ст. 52 п. 1 пп. 1) ТК РК» |
| «88 статья ТК» | «ст. 88 ТК РК» |
| «статья 63 Социального кодекса» | «ст. 63 Социального кодекса РК» |
| «КоАП ст 86» | «ст. 86 КоАП РК» |

## Дисклеймер (обязательный)

К каждому ответу необходимо добавлять в конце:

```
⚠️ Данный ответ носит информационный характер и не является юридической 
консультацией. Для решения конкретных правовых вопросов рекомендуется 
обратиться к квалифицированному юристу. Ссылки на нормативные акты 
приведены на действующую редакцию по состоянию на дату запроса.
```

## Интеграция в системный промпт

Этот Skill встроен в системный промпт синтезатора (`packages/rag/prompts.py`).
Правила форматирования активируются автоматически при каждом ответе на юридические вопросы.
Skill вынесен отдельно от промпта для переиспользования во всех агентах без дублирования.
