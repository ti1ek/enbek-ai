# enbek MCP

Локальный MCP-сервер для работы с Трудовым кодексом Республики Казахстан.  
Совместим с Claude Desktop, Claude Code, Cursor и Windsurf.

Персональные данные (ФИО, ИИН, названия организаций, БИН и др.) маскируются локально на устройстве пользователя до отправки любого запроса во внешние сервисы.

---

## Архитектура

```
AI-клиент (Claude Desktop / Cursor / Windsurf / Claude Code)
        │
        ▼
┌─────────────────────────────────────────┐
│              enbek MCP                  │
│                                         │
│  tools.py                               │
│  ├── mask_pii          (инструмент)     │
│  ├── retrieve          (инструмент)     │
│  └── search_labor_code (инструмент)     │
│                                         │
│  lib/masker.py    ← Ollama (локально)   │
│  lib/retriever.py ← Qdrant (облако)     │
└─────────────────────────────────────────┘
        │
        ▼ только маскированный текст
  OpenAI API (эмбеддинги) → Qdrant (поиск по ТК РК)
```

## Инструменты

### `mask_pii`

Маскирует персональные данные в произвольном тексте. Обработка выполняется локально через Ollama — данные не передаются во внешние сервисы.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `text` | `string` | Текст, содержащий персональные данные |

**Маскируемые типы данных:**

| Тип | Пример | Метка |
|---|---|---|
| ФИО | Нурланов Асхат Бекович | `[PERSON_1]` |
| ИИН | 850312300123 | `[ИИН_1]` |
| Название организации | ТОО «Казмунайгаз» | `[COMPANY_1]` |
| БИН | 240340012345 | `[БИН_1]` |
| Номер телефона | +7 701 123 45 67 | `[PHONE_1]` |
| Email | user@company.kz | `[EMAIL_1]` |
| Адрес | ул. Абая 10, кв. 5 | `[ADDRESS_1]` |
| Сумма выплаты | 350 000 тг | `[AMOUNT_1]` |
| Номер документа | № ТД-2024/0047 | `[DOC_1]` |

---

### `retrieve`

Выполняет семантический поиск по векторной базе Qdrant и возвращает релевантные фрагменты статей Трудового кодекса РК без дополнительной обработки.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `query` | `string` | Поисковый запрос на русском языке |

**Требует:** `OPENAI_API_KEY` для генерации эмбеддингов (`text-embedding-3-small`, 1536 dim).

---

### `search_labor_code`

Последовательно выполняет маскировку персональных данных и семантический поиск по Трудовому кодексу РК. Рекомендуется для запросов, содержащих персональные данные.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `query` | `string` | Вопрос или описание ситуации на русском языке |

**Требует:** `OPENAI_API_KEY`.

## Требования

| Компонент | Версия | Назначение |
|---|---|---|
| Python | 3.11+ | Среда выполнения |

| AI-клиент с поддержкой MCP | — | Claude Desktop / Cursor / Windsurf / Claude Code |

## Установка

**1. Клонирование репозитория и запуск установщика**

```bash
git clone https://github.com/ti1ek/enbek-ai.git
cd enbek-ai/mcp
bash install.sh
```

Установщик выполняет:
- установку Ollama (если отсутствует)
- загрузку модели `llama3.2:3b`
- установку Python-зависимостей (`pip install -r requirements.txt`)
- создание файла `.env` из шаблона `.env.example`

**2. Настройка переменных окружения**

Откройте созданный файл `mcp/.env` и укажите OpenAI API ключ:

```env
OPENAI_API_KEY=sk-...
```

## Подключение к AI-клиенту

Конфигурация MCP-сервера идентична для всех поддерживаемых клиентов.  
Замените `/полный/путь/до/enbek-ai` на абсолютный путь на вашем устройстве.

### Claude Desktop

Файл конфигурации: **Settings → Developer → Edit Config**

```json
{
  "mcpServers": {
    "enbek": {
      "command": "python",
      "args": ["/полный/путь/до/enbek-ai/mcp/server.py"],
      "env": {
        "OPENAI_API_KEY": "sk-ваш-ключ"
      }
    }
  }
}
```

Перезапустите Claude Desktop для применения изменений.

### Claude Code

```bash
claude mcp add enbek python /полный/путь/до/enbek-ai/mcp/server.py \
  --env OPENAI_API_KEY=sk-ваш-ключ
```

Либо добавьте конфигурацию вручную в `~/.claude/claude_desktop_config.json` в формате, аналогичном Claude Desktop.

### Cursor

Файл конфигурации: `~/.cursor/mcp.json` или **Settings → Features → MCP → Add new server**

```json
{
  "mcpServers": {
    "enbek": {
      "command": "python",
      "args": ["/полный/путь/до/enbek-ai/mcp/server.py"],
      "env": {
        "OPENAI_API_KEY": "sk-ваш-ключ"
      }
    }
  }
}
```

### Windsurf

Файл конфигурации: **Settings → MCP Servers → Add**

```json
{
  "mcpServers": {
    "enbek": {
      "command": "python",
      "args": ["/полный/путь/до/enbek-ai/mcp/server.py"],
      "env": {
        "OPENAI_API_KEY": "sk-ваш-ключ"
      }
    }
  }
}
```

