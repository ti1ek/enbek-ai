# enbek MCP

**Локальный MCP-сервер — задавай вопросы по Трудовому кодексу РК прямо в Claude Desktop.**  
Персональные данные сотрудников (ФИО, ИИН, адреса) маскируются на твоём компьютере и никогда не уходят в облако.

---

## Как это работает

```
Ты в Claude Desktop
        │
        ▼
┌──────────────────────────────────┐
│        enbek MCP  (локально)     │
│                                  │
│  1. Маскировка ПДн               │  ← Ollama на твоём компьютере
│     «Асхат Нурланов» → [PERSON_1]│    модель llama3.2:3b (~2 GB)
│     «ИИН 850312...» → [ИИН_1]   │
│                                  │
│  2. Поиск по ТК РК               │  ← Qdrant (база статей ТК)
│     эмбеддинги через твой        │    твой OpenAI ключ
│     OpenAI API ключ              │
└──────────────┬───────────────────┘
               │  только маскированный текст + статьи ТК
               ▼
         Claude Desktop
         (твоя подписка)
               │
               ▼
         Ответ со ссылками на статьи ТК РК
```

### Что нужно от тебя

| Что | Зачем | Стоимость |
|-----|-------|-----------|
| [Ollama](https://ollama.ai) | Маскировка ПДн локально | Бесплатно |
| OpenAI API ключ | Эмбеддинги для поиска | ~$0.0001 за запрос |
| [Claude Desktop](https://claude.ai/download) | Финальный ответ | Твоя подписка |

База статей Трудового кодекса РК уже встроена — отдельно ничего качать не нужно.

## Что скрывается автоматически

| Тип данных | Пример → замена |
|---|---|
| ФИО | Нурланов Асхат → `[PERSON_1]` |
| ИИН | 850312300123 → `[ИИН_1]` |
| Телефон | +7 701 123 45 67 → `[PHONE_1]` |
| Email | ashat@company.kz → `[EMAIL_1]` |
| Адрес | ул. Абая 10, кв. 5 → `[ADDRESS_1]` |
| Сумма зарплаты | 350 000 тг → `[AMOUNT_1]` |
| Номер договора | № ТД-2024/0047 → `[DOC_1]` |

## Установка

### 1. Установи Ollama

```bash
# macOS
brew install ollama

# Windows / Linux — скачай с https://ollama.ai

# Скачай модель (~2 GB, один раз)
ollama pull llama3.2:3b
```

### 2. Скачай enbek MCP

```bash
git clone https://github.com/ti1ek/enbek-ai.git
cd enbek-ai/mcp
pip install -r requirements.txt
```

### 3. Создай файл с ключом

```bash
cp .env.example .env
```

Открой `.env` и вставь свой OpenAI ключ:

```env
OPENAI_API_KEY=sk-...
```

### 4. Подключи к Claude Desktop

Открой **Claude Desktop → Settings → Developer → Edit Config** и добавь:

```json
{
  "mcpServers": {
    "enbek": {
      "command": "python",
      "args": ["/полный/путь/до/enbek-ai/mcp/server.py"],
      "env": {
        "OPENAI_API_KEY": "sk-твой-ключ"
      }
    }
  }
}
```

Перезапусти Claude Desktop. В поле ввода появится иконка инструмента **enbek**.

## Пример использования

Вставляешь в Claude:

> *Проверь этот договор: Нурланов Асхат, ИИН 850312300123, принят на должность менеджера с окладом 350 000 тг. Испытательный срок — 6 месяцев.*

enbek MCP автоматически:
1. Маскирует: `[PERSON_1], ИИН [ИИН_1], должность менеджера, оклад [AMOUNT_1], испытательный срок — 6 месяцев`
2. Находит статьи 36–38 ТК РК об испытательном сроке
3. Claude отвечает: *«Испытательный срок 6 месяцев нарушает ст. 36 ТК РК — максимум 3 месяца для рядовых сотрудников»*

ФИО и ИИН сотрудника на серверы OpenAI и Anthropic **не попали**.

---

## Доступные инструменты

**`search_labor_code`**  
Поиск по Трудовому кодексу РК. Принимает вопрос или описание ситуации, возвращает релевантные статьи с цитатами.

**`analyze_document`**  
Анализ трудового документа (договор, приказ, уведомление) на соответствие ТК РК.
