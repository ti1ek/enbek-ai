# Enbek AI — MCP Server

ИИ-консультант по трудовому праву Казахстана для Claude Desktop.  
Работает локально: персональные данные сотрудников **не покидают ваш компьютер**.

## Что умеет

| Инструмент | Описание |
|---|---|
| `ask_labor_law` | Ответ на вопрос по ТК РК, Социальному кодексу, приказам Минтруда и НП ВС РК с цитатами и ссылками |
| `mask_pii` | Маскирует ИИН, ФИО, телефоны, IBAN в тексте перед отправкой в LLM |

## Быстрый старт

### Требования
- macOS (Windows — в разработке)
- [Claude Desktop](https://claude.ai/download)
- OpenAI API ключ ([получить](https://platform.openai.com/api-keys)) — ~$1–3/месяц при активном использовании

### Установка

```bash
git clone https://github.com/enbek-ai/enbek-ai.git
cd enbek-ai
chmod +x apps/mcp_server/setup.sh
./apps/mcp_server/setup.sh
```

Скрипт спросит ваш OpenAI ключ и автоматически пропишет всё в Claude Desktop.

После установки **перезапустите Claude Desktop** — в чате появится иконка 🔨.

## Как использовать

### Вопрос по трудовому праву
```
Можно ли уволить сотрудника находящегося на больничном?
```

### Вопрос с документом сотрудника
```
Проверь законность этого приказа об увольнении:

Приказ №45 от 12.05.2025
Абдрахманов Серик Бекович, ИИН 850612350219
Уволен по подпункту 2 пункта 1 статьи 52 ТК РК...
```
> ИИН и ФИО будут автоматически заменены на `[IIN_1]` и `[PERSON_1]` до отправки в OpenAI.

## Защита персональных данных

```
Ваш документ (с ИИН, ФИО)
        ↓
mask_pii — запускается локально на вашем Mac
        ↓
[IIN_1] уволен по ст.52 — только это уходит в OpenAI
        ↓
Ответ с цитатами ТК РК
```

Реальные персональные данные **не покидают ваш компьютер**.

## Правовая база

- Трудовой кодекс РК (действующая редакция)
- Социальный кодекс РК
- КоАП РК (трудовые нарушения, whitelist статей)
- Приказы Министерства труда и социальной защиты
- Нормативные постановления Верховного суда РК

## Требования к OpenAI ключу

Рекомендуемый тариф: **gpt-4.1-mini** (~$0.001 за вопрос).  
Примерный расход: $1–3 в месяц при активном использовании.
